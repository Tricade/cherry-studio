# Agent Note: 侧栏项目工作区

Status: implemented

[English](2026-11-05-projects-workspace.md) | 中文

## 问题

项目管理隐藏在会话显示菜单中。准备团队时，需要切换到智能体和知识库页面，然后返回项目分配新资源。

## 决策

项目拥有独立的应用入口和路由。左侧列出所选项目的团队成员及其会话，中间复用智能体会话界面。创建、打开或分叉项目会话时，路由始终保留项目。智能体页面的项目菜单打开同一工作区。升级时一次性将项目固定在非空的侧栏快捷方式中，保留原有顺序，新安装默认也显示项目。

项目设置对话框复用现有的智能体和知识库创建表单。创建成功后选中资源，保存时持久化分配关系。用户也可以从团队成员中指定项目协调员。当前项目和成员资格决定该工作区可以打开哪些会话。

## 备选方案

复制项目编辑器会重复校验和删除逻辑。为项目另设智能体或知识库存储会阻止已有资源复用，并需要新的数据契约。

## 影响

创建可复用资源与保存项目分配是两项独立操作。取消项目编辑后，新资源仍可供以后使用。

## 验证

- AC1 — Electron 44.9.3 在升级后的独立测试配置侧栏中显示项目。SQLite 填充器测试验证自定义顺序、取消固定后的状态以及有意清空的侧栏得到保留。
- AC2 — Electron 项目编辑器在创建智能体和知识库时保留原有草稿。保存后持久化两个选中资源的 ID 和同一个共享工作区。渲染进程项目测试也验证保存时发送的明确选择。
- AC3 — 渲染进程测试验证项目会话选择排除其他项目及已移除成员的会话，且新会话保留项目、选定成员和工作区。数据库测试验证成员资格检查和协调员分配。在独立的 Electron 44.9.3 测试中，升级已有数据的配置后设置协调员并在项目内打开新会话，智能体页面的显示偏好保持原值。
