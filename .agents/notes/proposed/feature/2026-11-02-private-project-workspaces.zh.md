# Agent Note: 私有项目工作区与提供商配额

Status: proposed

[English](2026-11-02-private-project-workspaces.md) | 中文

## 问题

渲染图表和链接图标可能在用户未另行操作时联系远程服务。浏览器观察结果可能暴露查询参数及片段中的秘密。诊断上传缺少内容预览和类别选择；更新与备份控件没有说明全部传输数据。代理会话缺少项目容器，而令牌统计无法代表订阅配额。

## 提案

图表渲染及装饰性链接图标保持本地处理。从面向模型的浏览器 URL 元数据中删除凭据、查询字符串及片段，包括相对链接目标；保留实际导航和元素引用。这不承诺隐藏任意页面内容或 URL 路径中的秘密。

使用固定为 `1.2026.9`、采用 MIT 许可证的 `@plantuml/core` npm 引擎，捆绑主题、表情、图标及 Viz。在具有严格 CSP 的本地沙盒 HTML 资源中运行，禁用外部资源加载器并净化离线 SVG 输出。不支持外部包含文件及下载的标准库；禁止回退到远程渲染。

根据明确选择的类别在本地准备诊断包，展示所准备归档的实际内容和目标地址，并在确认后上传同一归档。允许切换定时更新检查，准确说明请求元数据及地区查询。在手动和定时备份控件旁展示备份内容、凭据、目标、归档保护方式和远程传输说明。

在用量页面添加只读提供商配额报告，与令牌统计分开。展示提供商报告的已用百分比、时间窗口、重置时间、模型或共享配额范围，以及可用的余额或优惠额度信息。订阅内用量的额外使用费用为零；付费超额用量单独展示。缺失数据标为不可用，绝不通过令牌估算。只读取所选账户或经验证匹配的账户；绝不兑换额度或扩展登录权限。

配额由用户手动刷新且不持久化。Codex 使用已安装 CLI 的 `account/rateLimits/read`，严格匹配 Cherry 账户，并已对照官方 `rust-v0.166.0-alpha.5.1` 协议核实。Claude 使用固定为 `0.3.284` 的 SDK 实验性用量控制接口，设置 `skipBehaviors: true`，不发送输入提示，并沿用现有 CLI 登录配置。CherryIN 返回原始余额单位，不请求个人资料，并在凭据变更时拒绝结果。其他登录方式明确标为不支持。未知货币比例保留提供商原始单位；现有令牌价格估算仍是 API 等值分析，不代表订阅账单。Claude 受管理策略的钩子仍遵循 SDK 的策略优先级。

添加包含可复用代理成员、指令、工作区和共享知识库的项目。每个会话至多属于一个项目。项目会话仅使用项目明确选择的知识范围；不会将代理的全局知识绑定复制到项目中。已有非项目会话保持原有行为。项目成员关系不意味着自动编排。

每个项目拥有一个已注册的用户工作区，创建后不能重新指定。分叉会话及代理创建的子会话保留所属项目，并要求代理仍是团队成员。移除成员会保留历史，但在重新加入前禁止启动新轮次。身份和记忆按项目及代理分别存放于 `Data/Projects/<projectId>/<agentId>`；只有指令、工作区文件及所选知识库共享。连接在下一轮开始时重新核对已修改的项目数据，项目后续消息排队等待而不引导正在运行的轮次。项目和工作区删除会拒绝仍有正常或回收站会话引用的情况；外部工作区文件始终保留。孤立数据清理遵循现有的新鲜度和恢复保护规则，回收无引用的内部项目记忆。完整备份包含这些记忆，精简备份不包含，但两者都保留项目定义和历史。这些规则限定自动提供的上下文，而不取代显式外部工具或文件系统权限。

仓库所有者还要求保留提供商的模型限制并安全处理 Pi 传输恢复。模型列表和存储应保留提供商报告的有效输入、输出限制，不覆盖用户明确设置的值，也不通过将输入与输出限制相加来虚构上下文窗口。Pi 在尚无可见输出时保留原生传输重试；一旦出现非空文本、推理或已启动的工具，失败时即停止并保留部分结果。只有整个提示执行结束后，才恢复原先的内存重试设置。长度与压缩恢复仍由原生机制负责。

导入模型时，有效的发现限制优先于注册表默认值，并保留明确支持的能力。只有 LiteLLM 预设会从已配置的服务器请求可选组元数据，超时为五秒，并且仅匹配列表中的精确模型 ID；元数据不可用不会导致列表失败。LiteLLM 1.106.6 报告的是组内最大值，并不保证每个后端都支持这些限制。无法匹配的别名保留未知的组元数据，不猜测其后端。已有模型不会被覆盖。Pi 将已知上下文与输入限制中较小的值用作保守的运行时边界，但不存储虚构的窗口值；其原生 1.4.0 请求逻辑会根据估算预留上下文余量。

分支所有者已在任务对话中直接授权实施。本分支的授权不代表上游规格审批。初始基线为 `61120d19e1af69c9bd9c93b5620143b448a1df0a`；此后分支及实现已与上游 `4d1af48cdb68039c67bec71a05c0ce3190b1ebde` 同步。仓库固定 Node `24.18.1`、pnpm `12.6.0`、Electron `44.9.3` 及 Claude Agent SDK `0.3.284`。

## 考虑过的替代方案

以静默回退方式保留远程渲染器仍会泄露数据。已知秘密参数名列表无法覆盖未知名称。在重建诊断归档前仅预览来源数量，不能保证用户查看过实际提交的内容。通过令牌数估算配额百分比会歪曲提供商限制。为每个项目复制代理会失去复用能力，而全局修改代理的知识绑定会使上下文跨项目泄露。

## 验收标准

- AC1 — 图表预览在本地渲染，无法通过网络获取图表包含文件、图片或其他资源。 (verification: unit | renderer | packaged artifact)
- AC2 — 浏览器 URL 元数据对绝对和相对链接均省略凭据、查询字符串及片段，同时保留元素操作能力。 (verification: unit | Electron)
- AC3 — 渲染链接图标不会联系第三方图标服务或链接网站，即使存在旧的远程缓存。 (verification: renderer)
- AC4 — 诊断上传要求类别选择、准确的内容预览和明确确认；更改选择会使已准备的上传失效。 (verification: unit | renderer)
- AC5 — 更新控件说明接收方及传输的元数据；禁用定时检查会停止这些检查，同时保留显式检查。 (verification: unit | renderer)
- AC6 — 本地及远程备份控件在使用前说明内容、凭据、归档未加密、目标和远程传输。 (verification: renderer)
- AC7 — 用量页面展示受支持提供商的真实配额、重置时间及范围，与令牌和付费超额用量分开；未知或不匹配的账户绝不显示虚构数值。 (verification: unit | renderer)
- AC8 — 项目复用现有代理、组织会话并共享项目指令、工作区文件及明确选择的知识，不暴露其他项目的上下文。 (verification: unit | renderer | Electron)
- AC9 — 追加数据库迁移及可选项目关联后，已有会话、数据和备份恢复功能保持正常。 (verification: unit)
- AC10 — 有效的提供商模型限制在列表和持久化过程中得以保留，不覆盖显式设置，也不虚构合并后的上下文窗口。 (verification: unit | renderer)
- AC11 — Pi 对符合条件的无输出失败进行重试，但保留可见的部分回答而不自动重放；后续显式轮次和已有重试设置保持可用。 (verification: unit | native SDK)

## 风险

删除 URL 参数会减少模型可见信息；元素引用可在不重建含秘密的 URL 的情况下保留导航。本地 PlantUML 需要捆绑引擎及严格的资源隔离。诊断预览本身可能包含私人文本，确认前必须保持本地。提供商配额 API 随登录方式和版本而异；不可用能力必须明确标注。项目有意共享物理工作区，因此删除操作不得移除仍被引用的文件。任何单个测试门禁都不能证明已安装应用绝不会意外传输数据。
